# 物品貸出管理アプリ

アルバイト先での物品貸し出しを管理するWebアプリです。  
物品の選択から登録番号の入力・貸出履歴の確認・返却管理まで、1つの画面で完結します。

---

## 主な機能

- **カテゴリ選択から貸出登録まで1画面で完結**
  - 卓球ラケット、Switchコントローラー、ボードゲーム・タブレット・その他、充電器類の4カテゴリを用意
- **カテゴリごとの選択方式を使い分け**
  - 卓球ラケットは複数選択可能
  - Switchやコントローラー、ジョイコンは1つだけ選択
  - 充電器類は複数選択可能
- **ボードゲームは一覧選択と直接入力の両方に対応**
  - 既存のゲーム名をボタンで選択
  - 「その他」の名称は自由入力で登録可能
- **貸出中の物品はグレーアウトして選択不可化**
  - 重複貸出を防ぎ、借りられないものが明確になる
- **登録番号を入力して一括で貸出登録**
- **貸出履歴を最新順で一覧表示**
- **返却確認チェックを記録**
- **履歴の個別削除・全件削除に対応**
- **トースト通知で操作完了をお知らせ**

## 技術スタック

| 技術          | 用途                                 |
| ------------- | ------------------------------------ |
| HTML          | 画面構造・レイアウト                 |
| CSS           | 画面デザイン・レスポンシブ対応       |
| JavaScript    | 画面遷移・動的ボタン生成・データ管理 |
| localStorage  | ブラウザ内で貸出データを永続保存     |

### フレームワーク・ビルドツールを使用しない理由

このアプリはアルバイトの現場で実際に使用することを想定して開発しました。  
将来的に自分が離れた際に、後任の担当者がコードを引き継いで修正できることを重視しています。

- **ファイルが1つ**のため、VS CodeのLive Serverを起動するだけで動作確認できる
- Node.jsやパッケージのインストールが不要で、環境構築ゼロで始められる
- フレームワーク固有の知識がなくても、HTML/CSS/JavaScriptの基礎があれば読める
- 物品の追加・削除などよくある変更は、ファイル上部の設定オブジェクトを編集するだけで対応できる

## ファイル構成

```
/
├── index.html        # アプリ本体（HTML・CSS・JavaScriptを1ファイルに集約）
├── tabletennis.png   # 卓球ラケットのメニュー画像
├── controller.png    # コントローラーのメニュー画像
├── boardgame.png     # ボドゲ・その他のメニュー画像
└── cord.png          # 充電器類のメニュー画像
```

## 使い方

1. `index.html` をブラウザで開く、または VS Code の Live Server で起動する
2. ホーム画面で借りたい物品カテゴリを選択する
3. 表示された候補から番号やゲーム名を選ぶ
4. 画面下部の登録番号欄に担当者の番号などを入力する
5. 「借りる」を押して貸出記録を保存する
6. 返却時は「貸出履歴」画面を開き、該当行のチェックボックスをオンにする

## カスタマイズ方法

`index.html`内のJavaScript冒頭にある設定オブジェクトを変更するだけで、画面の項目を調整できます。

### カテゴリの追加

```javascript
const MENU_CONFIG = [
  { label: "卓球ラケット", screen: "racket", image: "tabletennis.png" },
  // ここに追加する
];
```

### 物品番号の追加・変更

```javascript
const PAGE_CONFIG = {
  racket: [
    {
      areaId: "racketArea",
      label: "卓球ラケット",
      type: "multi",
      list: [1, 2, 3, 4],
      //       ↑ ここに追加する
    },
  ],
};
```

### ボードゲーム名の追加

```javascript
const BOARDGAME_LIST = [
  "トランプ",
  "UNO",
  // ここに追加する
];
```

## データの保存場所

貸出履歴はブラウザの `localStorage` に保存されます。  
保存できる履歴は最大300件で、上限を超えると最も古い記録から自動削除されます。  
同じデバイス・同じブラウザ内でのみ保存され、他の端末や別ブラウザとは共有されません。
